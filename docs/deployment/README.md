# Deployment Documentation

This section covers local development, staging validation, and production release procedures.

- `local-development.md` — Developer setup and safe local configuration.
- `staging.md` — Pre-production checks.
- `production.md` — Release and post-deployment verification.

Use the actual commands in `package.json` and the configured Render service. Do not assume a health endpoint, build command, or start command until verified.
