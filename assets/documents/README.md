Directory: assets/documents/

Overview

This directory contains the public-facing document resources used by the MedOrbits platform. Resources are organized into topic-specific folders to make educational, career-development, financial-planning, and international-study materials easier to maintain and discover.

File Formats and Naming

• Prefer PDF for finalized, printable documents.
• Use Markdown (.md) for documentation and resource indexes.
• Use descriptive, lowercase kebab-case names, such as admission-document-checklist.pdf.
• Keep files in the category directory that best matches their primary purpose.
• Update the relevant folder README whenever resources are added, removed, renamed, or reorganized.

Publishing and Maintenance

Before publishing a document:

1. Confirm that the content is accurate, current, and appropriate for its intended audience.
2. Check spelling, formatting, links, page layout, and accessibility.
3. Verify that the document does not expose personal, confidential, or internal information.
4. Confirm that any regulatory, admission, fee, or deadline information is clearly dated and checked against an authoritative source.
5. Ensure the file name and directory placement follow the conventions above.
6. Update relevant README files and any website links or resource indexes that reference the document.

Accessibility

• Use readable typography and sufficient contrast.
• Structure documents with meaningful headings and logical reading order.
• Provide descriptive link text instead of raw URLs where practical.
• Avoid relying on color alone to communicate important information.
• Where possible, provide accessible HTML or text alternatives for essential information.

Brand and Design

Use the established MedOrbits visual identity for branded documents. The preferred direction is Royal Burgundy and Champagne Gold. Maintain consistent typography, spacing, headings, and footer details while ensuring that content remains legible and accessible.

Important Notes

• Do not assume that every file in these directories is automatically approved for public distribution.
• Do not commit secrets, credentials, private student records, or personally identifiable information.
• Keep source files and editable working documents separate from approved public downloads when necessary.
• Use only verified, current links when referring readers to external institutions or official requirements.
