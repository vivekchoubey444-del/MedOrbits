1. Purpose

The MedOrbits Checklists Library provides practical, printable resources to help students, applicants, graduates, and job seekers organise education planning, admissions, applications, examination preparation, career development, and study-abroad activities.

These resources are general-purpose planning aids designed to help users track tasks, prepare documents, and verify requirements before taking action.

4. File Naming Standards

* Use lowercase, descriptive, hyphen-separated filenames.
* Use .pdf for printable checklist resources.
* Keep one canonical copy of each resource.
* Use stable relative paths in the manifest and website links.
* Update all references whenever a file is renamed or moved.
* Avoid personal names, application numbers, or sensitive information in filenames.

5. Design and Accessibility

All resources should follow the MedOrbits Royal Burgundy and Champagne Gold design system.

* Use readable typography and clear heading hierarchy.
* Maintain sufficient text contrast and print-friendly spacing.
* Provide clearly distinguishable checkboxes and actionable instructions.
* Ensure documents remain understandable when printed in grayscale.
* Do not communicate essential information through colour alone.
* Apply branding within the PDF generation process; website CSS does not automatically style PDF files.

6. Content Accuracy and Verification

These resources provide general planning guidance and are not official notices.

Before publication or revision:

1. Review all instructions for accuracy, clarity, and completeness.
2. Verify changing eligibility rules, deadlines, fees, documentation, examination requirements, and immigration conditions through relevant official sources.
3. Record source URLs and review dates when information may change.
4. Avoid presenting institution-specific rules as universal requirements.
5. Remove outdated or misleading instructions.
6. Make clear when a task depends on the user’s institution, programme, location, or circumstances.

Do not claim that a checklist has been officially verified unless the relevant checks have actually been completed.

7. PDF Quality Assurance

Before publishing a new or updated PDF:

* Confirm the file exists at its documented path.
* Open the PDF and inspect text rendering, page breaks, margins, and layout.
* Check checkbox readability and printing quality.
* Review metadata, comments, embedded files, and hidden content.
* Confirm the PDF works on common mobile and desktop readers.
* Test the public download URL after deployment.
* Update MANIFEST.json and relevant category documentation.

8. Website Integration

Use the canonical public asset paths when linking to resources.

Example:

/assets/documents/checklists/admissions/admissions-checklist.pdf

Ensure that:

* The deployed directory structure matches the documented paths.
* Download links use descriptive and accessible text.
* Every manifest entry points to an existing file.
* Server responses use the appropriate PDF content type.
* Renamed or removed files do not leave broken links.

9. Privacy and Security

This directory contains public frontend resources.

Permitted content:

* Blank checklists and worksheets.
* Approved general educational and career guidance.
* Publicly downloadable planning templates.

Do not publish:

* Completed checklists containing personal information.
* Identity documents, private student records, or financial documents.
* Passwords, API keys, credentials, or confidential internal files.
* Unreviewed files containing private metadata or embedded information.

Users should store completed checklists in private storage.

10. Limitations and Disclaimer

MedOrbits checklists are informational planning resources. They do not replace official instructions or qualified professional advice and do not guarantee admission, employment, examination success, scholarship eligibility, loan approval, or visa approval.

Users must independently verify applicable requirements, fees, deadlines, eligibility conditions, recognition, and documentation with the relevant institution, regulator, examination authority, employer, financial provider, or government authority.

11. Maintenance

Review this library whenever a resource is added, updated, renamed, or retired.

Keep the root README, category README files, MANIFEST.json, and website links synchronised. Remove obsolete public copies when they are no longer appropriate.
