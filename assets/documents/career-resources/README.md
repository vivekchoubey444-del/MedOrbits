1. Overview

The career-resources/ directory contains approved downloadable resources that help users prepare for employment, internships, career transitions, and professional development.

Resources may include practical guides, editable templates, checklists, worksheets, and planning tools covering:

* Resume and CV preparation
* Cover letters and job-application emails
* Interview preparation and follow-up
* Job-search planning and vacancy verification
* Internship applications and preparation
* Workplace communication and professional conduct
* Career planning and professional development
* Job-offer evaluation and joining preparation

These are supported resource areas, not a guarantee that every resource exists. Only publish files that have been created, reviewed, and approved.

4. Resource Content Standards

Every resource should have a clear purpose, intended audience, and practical outcome.

Where appropriate, include:

1. Title and purpose: Explain what the resource helps the user accomplish.
2. Audience: Identify the relevant user group.
3. Actionable guidance: Provide useful steps, examples, exercises, or checklists.
4. Customization instructions: Explain which information users should adapt.
5. Sources: Reference reliable sources for factual or regulated guidance.
6. Review information: Record the last review date when relevant.
7. Limitations: Explain when requirements vary by employer, industry, location, or individual circumstances.

Examples must be clearly identified as illustrative. Never invent qualifications, work experience, vacancies, salary figures, placement statistics, endorsements, or employment outcomes.

5. File Formats and Naming

Use the format that best supports the resource’s purpose.

Format	Preferred use
PDF	Published guides, checklists, and print-ready resources
DOCX	Editable resumes, cover letters, and worksheets
XLSX	Application trackers and planning spreadsheets
CSV	Portable tabular data, where appropriate
Markdown	Repository documentation and resource instructions

Use lowercase, descriptive, hyphen-separated filenames.

Examples:

resume-writing-guide.pdf
resume-template-editable.docx
cover-letter-writing-guide.pdf
interview-preparation-guide.pdf
job-application-tracker.xlsx
internship-application-guide.pdf
professional-communication-guide.pdf

Naming rules:

* Use one clear topic per filename.
* Avoid spaces, ambiguous abbreviations, and unnecessary special characters.
* Do not include personal information in filenames.
* Avoid names such as final2.pdf or new-document.pdf.
* Record version information when multiple editions need to be distinguished.
* Update references whenever a file is renamed or moved.

6. Accessibility and Document Quality

All published resources should be readable, usable, and accessible.

* Use meaningful titles and a logical heading hierarchy.
* Choose readable fonts and maintain sufficient color contrast.
* Prefer selectable text over image-only PDFs.
* Use descriptive links and accessible tables.
* Check page breaks, margins, tables, and document exports.
* Ensure editable templates work in compatible word-processing applications.
* Test documents on mobile screens and when printed.
* Explain specialized terminology where necessary.

MedOrbits’ Royal Burgundy and Champagne Gold design system may be used for branded resources. Readability, accessibility, and print usability take priority over decorative styling.

7. Accuracy and Review

Before publication:

* Verify factual claims and external references.
* Review time-sensitive information, eligibility criteria, and application instructions.
* Distinguish general advice from employer-specific requirements.
* Use official sources for regulated or government-related information where applicable.
* Remove obsolete or misleading content.
* Confirm that examples are clearly illustrative and accurate.
* Record review dates for resources likely to become outdated.

Do not describe a vacancy, programme, deadline, or opportunity as current unless it has been appropriately verified.

Resources involving employment law, immigration, licensing, or other regulated matters must not present general guidance as a substitute for official requirements or qualified professional advice.

8. Privacy, Security, and Copyright

This directory must be treated as publicly accessible whenever its files are served as static website assets.

Never store the following here:

* Private resumes or completed job applications
* Identity documents, passports, certificates, or confidential records
* Personal contact details belonging to real applicants
* Private interview notes or candidate assessments
* Confidential employer documents or unpublished recruitment records
* Passwords, API keys, access tokens, or other secrets

Use clearly marked fictional placeholders in public templates.

Obtain appropriate authorization before publishing testimonials, photographs, employer logos, or third-party materials. Respect copyright and licensing requirements.

Private candidate records, applications, and employer submissions must be stored in appropriately protected systems. Access restrictions must be enforced by the server; hiding a download link does not protect a public file.

9. Website Integration

Career resources may be linked from relevant MedOrbits pages, including career guidance, jobs, internships, resume assistance, and professional development.

Integration requirements:

* Provide descriptive resource titles and short summaries.
* Display file formats and file sizes where useful.
* Confirm that the file exists at the expected deployment path.
* Test download links on mobile and desktop.
* Use the correct public URL for the deployed project.
* Apply appropriate access controls to non-public content.
* Update all references when files are moved, renamed, replaced, or withdrawn.
* Avoid exposing private documents through public download URLs.

Example URL, subject to deployment configuration:

/assets/documents/career-resources/resume-cv/resume-writing-guide.pdf

This path must be verified against the actual deployed website before it is used in HTML or JavaScript.

10. Manifest and Inventory Management

MANIFEST.json is the central inventory for the career-resources directory.

When maintaining the manifest:

* List the root README and actual resource files.
* Use relative paths consistent with the declared root.
* Keep category inventories consistent with the master file list.
* Ensure each path is unique.
* Update the manifest when files are added, renamed, moved, or removed.
* Validate that listed files exist before release.
* Avoid counting directories as files.
* Do not claim that a manifest proves a file’s contents or publication quality.

The manifest is descriptive metadata, not an access-control mechanism or a substitute for server-side validation.

11. Maintenance Workflow

For each new or updated resource:

1. Define its audience and purpose.
2. Draft or revise the content.
3. Verify factual claims, examples, and references.
4. Review privacy, permissions, and licensing.
5. Check accessibility and formatting.
6. Apply the established naming conventions.
7. Place the file in the appropriate category.
8. Update the category README and MANIFEST.json as necessary.
9. Test the deployed URL and download behavior.
10. Remove obsolete links and manage superseded editions appropriately.

Keep related documentation and website-link changes in the same change set where practical.

13. Relationship to the MedOrbits Application

This directory stores downloadable documents, not application logic.

The website’s page layouts, navigation, resource search, download controls, authorization, and Royal Burgundy and Champagne Gold styling belong to the appropriate HTML, CSS, JavaScript, and backend components.

Keep resource documentation independent of those implementation details. Update this README only when the directory organization, publication rules, or resource-management conventions change.

14. Scope and Disclaimer

This README documents the purpose and recommended practices for assets/documents/career-resources/. It does not independently verify the existence, accuracy, or publication status of individual files.

Career resources provide general educational and professional guidance. They do not guarantee interviews, internships, employment, salaries, placements, or recruitment outcomes.

Users should verify role-specific requirements with employers and consult appropriate official authorities or qualified professionals when necessary.
