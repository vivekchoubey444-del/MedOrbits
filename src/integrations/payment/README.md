# Payment Integration
Set `PAYMENT_PROVIDER=razorpay` or `stripe`; configure provider secrets and install only the relevant SDK (`razorpay` or `stripe`). Amounts are integer smallest units (INR = paise), calculated server-side. Stripe requires HTTPS success/cancel URLs; enforce an application-owned URL allowlist too. The adapter does not implement local orders, refunds, subscriptions, tax, idempotency storage, or full event routing. Preserve exact raw webhook bytes, verify signatures before parsing, use unique event IDs and transactional/idempotent processing, and never mark a payment paid from a browser redirect alone.
